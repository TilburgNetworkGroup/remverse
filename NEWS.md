# remverse 0.2.0

* Re-exports key functions from 'remify', 'remstats', and 'remstimate' to
  provide a unified interface for relational event history analysis, spanning
  data processing, model estimation, and diagnostics.
* Added support for duration-extended relational event models, finite mixture
  and dyadic latent class models, frailty (random-effects) models, penalized
  estimation, and moving-window models.
* Added vignettes covering the full pipeline and the individual modeling
  workflows (durem, GLMM, glmnet, mixrem, window).
